# 🍽️ LetMeDine — Food Delivery Website (Dummy Project)

LetMeDine is a clean, modern, front‑end based food delivery website built using **HTML, CSS, and JavaScript**.  
It is designed as a **dummy/demo project** for academic submissions, portfolio showcases, or beginner-level practice.

This project simulates a real food delivery platform with pages like **Home, Menu, Cart, Checkout, Tracking, and Admin**, all powered using **static JSON data** and **localStorage**.

---

## 🚀 Features

### ✅ User Side
- Modern homepage with hero section  
- Menu page with food items  
- Add to Cart functionality  
- Cart page with quantity & total price  
- Checkout form (dummy)  
- Order tracking simulation  
- Fully responsive layout  

### ✅ Admin Side (Dummy)
- View all food items  
- Static JSON-based “database”  
- No authentication required  

### ✅ Technical Highlights
- Pure **HTML + CSS + JavaScript**  
- No backend required  
- Uses **localStorage** to store cart & order  
- Uses **JSON data** for food items  
- Works **offline** after images are added

## 🧪 How It Works

### **Menu Page**
- Loads food items from `data.js`
- Renders cards dynamically
- “Add to Cart” stores items in localStorage

### **Cart Page**
- Reads items from localStorage
- Calculates total price
- Allows removing items

### **Checkout Page**
- Simple form (name, address, phone)
- Saves order to localStorage
- Redirects to tracking page

### **Tracking Page**
- Simulates order status:
  - Preparing → On the way → Delivered

### **Admin Page**
- Displays all food items from JSON
- No backend or login required
